--Порядок запуска--


1. Скачайте zip-архив проекта и распакуйте содержимое в пустую директорию
2. Скачайте актуальную версию клиента PostgreSQL
3. Скачайте актуальную версию Node
4. Измените конфигурацию файла .env согласно настройкам вашей СУБД (обратите вниманеи, что пароль от базы должен быть строго в кавычках)
5. Находясь в директории server:
- 5.1 Выполните установку необходимых зависимостей командой npm install (или просто npm i)
- 5.2 Запустите миграции командой npx sequelize-cli db:migrate
- 5.3 Запустите сиды командой npx sequelize-cli db:seed:all
- 5.4 Запустите server командой npm run dev
6. Находясь в директории client:
- 6.1 Выполните установку необходимых зависимостей командой npm install (или просто npm i)
- 6.2 Запустите client командой npm run dev
- 6.3 Прейдите на указанный в терминале url или используйте ручной ввод в строке браузера (http://localhost:5173/)


P.S. В связи с возникающей избыточностью было принято не делить client-структуру на компоненты. Жду вашего фитбэка!
